# Systematic View Generation for Black–Litterman Portfolios

This repository contains a research project on systematic view generation for Black–Litterman portfolio construction.

The first stage compares three interpretable approaches for generating the Black–Litterman view vector $Q_t$:

- Historical expected-return views
- Momentum-based views
- Factor-based views

All approaches are evaluated within the same walk-forward Black–Litterman framework.
